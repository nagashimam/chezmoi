# Navigation (ジャンプ・移動) 設計方針

## 1. コア思想
- **「`]` で前進・跳躍し、何があっても `[[` で直前に戻る」** という単一のメンタルモデルに統一する。
- 戻りキーを `[d` や `[c` のように細分化せず、**万能脱出キー `[[`（Vim ジャンプリスト戻り `<C-o>`）** に一本化することで、迷いをゼロにする。
- すべてのジャンプ動作はジャンプリストに記録されるため、連続ジャンプ後も `[[` を連打すれば元の編集位置まで確実に遡れる。

---

## 2. ジャンプキーマップ一覧

### ナビゲーション基本（ジャンプ履歴）
| キー | 動作 | 実装 | 説明 |
| :--- | :--- | :--- | :--- |
| **`[[`** | **ジャンプ元に戻る** | `<C-o>` | 万能脱出キー。どのジャンプからでも直前に戻る |
| **`]]`** | **進む（やり直す）** | `<C-i>` | `[[` で戻った履歴を再び進む |

### LSP ジャンプ
| キー | 対象 | 英語・意味 | 説明 |
| :--- | :--- | :--- | :--- |
| **`]D`** | 定義元 | **D**efinition | 関数・コンポーネントの宣言場所へジャンプ |
| **`]t`** | 型定義 | **T**ype definition | 変数・Propsの `type` / `interface` 定義へジャンプ |
| **`]i`** | 実装 | **I**mplementation | interface等を実装している具体コードへジャンプ |
| **`]r`** | 参照一覧 | **R**eferences | シンボルが使用されている箇所一覧 |
| **`]d`** | エラー・警告 | **D**iagnostic | ファイル内の次のエラーまたは警告へジャンプ |
| **`]e`** | エラーのみ | **E**rror only | Warningを無視して、コンパイル/型エラーのみへジャンプ |

### Git ジャンプ (`gitsigns.nvim`)
| キー | 対象 | 英語・意味 | 説明 |
| :--- | :--- | :--- | :--- |
| **`]c`** | Git変更箇所 | **C**hange (hunk) | ファイル内の次の未コミット変更箇所へジャンプ |

### 構文・コード構造ジャンプ (`nvim-treesitter-textobjects`)
| キー | 対象 | 英語・意味 | 説明 |
| :--- | :--- | :--- | :--- |
| **`]f`** | 関数・メソッド | **F**unction | 次の関数定義へジャンプ（TS, Vue script, Go func） |
| **`]a`** | 引数・パラメータ | **A**rgument / param | 次の関数の引数位置へジャンプ |
| **`]k`** | ブロック・スコープ | Bloc**k** / scope | 次の `{}` や `if` / `for` スコープへジャンプ |
| **`]T`** | HTML/Vueタグ | **T**ag | Vue `<template>` や HTML 内の次のタグ要素へジャンプ |

### エディタ・リスト巡回
| キー | 対象 | 英語・意味 | 説明 |
| :--- | :--- | :--- | :--- |
| **`]q`** | Quickfix項目 | **Q**uickfix | 全体検索結果やビルドエラーの次の項目へジャンプ |
| **`]b`** | バッファ | **B**uffer | 次に開いているファイル（バッファ）へ切り替え |

## 3. バッティング検証結果
- **Herdr**: プレフィックス `Ctrl+;` と一切干渉しない。
- **Zsh**: ターミナル側キーバインドと独立。
- **Neovim標準**:
  - `]d`, `]D`, `]t`, `]i`, `]r` は旧C言語用マクロや空き領域を安全に上書き。
  - `<leader>f...` (Fuzzy), `<leader>l...` (LSP), `<leader>cp` (Herdr Context) と競合なし。
